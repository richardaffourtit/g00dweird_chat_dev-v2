## ghost1 — Crooked Grin

Use case: stylized-concept.
Asset type: production pixel-art character animation spritesheet for the g00dweird isometric Halloween chat world.
Input images: image 1 is the identity reference (the handmade ghost cutout ONLY; discard the photographed room). Image 2 is an existing game sprite STYLE reference for crisp visible pixel clusters, dark contour, restrained shading and game scale; do NOT copy its character design.
Primary request: faithfully translate the ghost in image 1 into one consistent pixel-art character and create a FOUR BY FOUR animation sheet, exactly 16 cells, four equal rows and four equal columns, on a genuinely TRANSPARENT ALPHA background.
Character identity: ivory sheet ghost, long strongly curved S-shaped neck, head cocked to the left, TWO ROUND BLACK EYES with tiny pale highlights, a broad jagged charcoal crescent grin across the base of the head, pale moss-green streaks down an otherwise warm ivory sheet, ragged scalloped trailing hem. NO arms, preserve the bend and long neck.
Canvas/layout: square 1024x1024 PNG; each of the sixteen invisible grid cells is 256x256. Character neutral height about 192 pixels, neutral foot/hem baseline y=224 inside each cell, centered x=128. Generous empty transparent gutters (at least 20 pixels) between cells. Never cross cell boundaries. No grid lines, no text, no labels, no numbers, no floor, no props, no cast shadows, no background scene. No checkerboard printed into the image.
Style: chunky hand-placed 16-bit game pixel art, controlled 12-18-color palette, clearly stepped edges and flat pixel clusters, dark plum outline; pixel scale consistent across every cell. Match the coarse pixel fidelity of reference 2 while retaining reference 1's distinctive shape and colors. No smooth vector art, no photographic texture, no fuzzy glow.
Animation layout from left to right:
ROW 1 — RISE (4 poses): small wispy crown emerging at the baseline; recognizable head emerging; head and upper torso emerging; entire neutral ghost fully emerged. The same ghost rises vertically through an invisible ground plane at y=224, lower hidden body simply absent/transparent. Keep visible head/facial proportions identical as it rises.
ROW 2 — FLOAT (4 seamless loop poses): full ghost gently drifts, hems curling left, neutral, curling right, near-neutral; subtle head bob and fabric sway. Constant body size, expression and identity.
ROW 3 — HAUNT (4 poses): full neutral ghost anticipates, leans toward viewer, fabric flares with a mischievous scare, returns close to neutral. Preserve facial identity and retain the original eye colors. Keep head size consistent, no new limbs.
ROW 4 — VANISH (4 poses): full ghost begins to sink, lower half disappears below baseline, only recognizable head remains at baseline, tiny wisps remain at baseline. All ground/background pixels fully transparent.
Quality constraints: exactly 4x4 cells, a single identical ghost character in every pose, aligned cell center and baseline, no missing cells, no extra characters or decorations. Preserve genuine alpha transparency and crisp game-ready edges.
